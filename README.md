# MyJira

Приложение состоящее из 2 страниц, где главная страница - страница всех текущих проектов, а 2 страница - канбан доска по каждому не удалённому проекту.
## Запуск

```npm
npm i
```

```npm
npm run dev
```

## Ссылка на приложение

```
npm run dev
```
